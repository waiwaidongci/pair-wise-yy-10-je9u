# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 客户建档，作品新增时归属客户，并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付、已交接。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 按客户和交接日期生成装匣候选名单；切换客户或交接日期会重算并自动勾选合格作品。
- 未退回前，一件作品只能归属于一个进行中或已交接批次；两窗口并发操作时会提示后到者占用批次。
- 非“待交付”、阴干未到、存在缺陷或被其他批次占用的作品列卡点，不能重复装匣或交接。
- 批次可办理交接；交接后作品状态与历史锁定。退回只解除占用并放回待交付，原批次、作品名单和操作历史保留。
- 支持主题、客户、状态、批次筛选，详情查看，localStorage 持久化和包含客户、作品、批次的 JSON 导出。

代码按三层组织：
- 数据层：存储键迁移、数据规范化、localStorage 读写。
- 规则层：唯一占用、装匣卡点、批次交接/退回判定。
- 页面层：新增、名单、看板、筛选、详情、导出和跨窗口刷新。
