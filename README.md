# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

作品流转：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷、意向客户和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付、已交付。
- 今日待阴干、缺陷作品、最近交付三类列表；支持筛选、排序、详情与缺陷登记。

交付批次（按客户 · 交接日期装匣）：
- 客户先建档（建批时也可直接建档），选客户与交接日期后系统重算装匣名单：
  同客户、计划交付不晚于交接日且完工的作品默认勾选。
- 一件作品在未退回前只归属一个在效批次；已被占用的作品会标明占用批次号，无法重复装匣。
- 条件不合逐条列卡点：阴干未到、存在缺陷、状态非「待交付」、进度未满、金粉未上、
  客户不符、计划交付晚于交接日期。卡点件不会被装入；交接时再复验一次。
- 修改批次的客户或交接日期，匣内合规性与候选名单立即重算。
- 交接后作品状态与流转历史锁定，不能改状态或登记缺陷。
- 客户退回只解锁把作品放回「待交付」并记录退回原因/时间，原批次与流水完整保留，
  退回件可再进入新批次。
- 多个窗口同时装匣：提交前以磁盘最新数据重判，后提交方会看到对方占用的批次号；
  其他窗口写入时本窗口看板与弹窗自动刷新。

数据、规则、页面三层分离（Store / Rules / UI）。数据以 localStorage 持久化
（键 `zfl42Data_v2`，自动迁移旧版 `zfl42Works`），导出 JSON 包含作品、客户与批次。
